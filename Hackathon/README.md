## 2-Step Launch Commands (PowerShell)

### Terminal 1: Launch Backend (Spring Boot 3.3.5)
```powershell
cd d:\DBMSE\Vechile_Service_Management\vehicle-service-booking-system\backend
.\mvnw.cmd spring-boot:run
```
*API is accessible at http://localhost:8080 (Swagger UI: http://localhost:8080/swagger-ui.html)*

### Terminal 2: Launch Frontend (React 18 + Vite)
```powershell
cd d:\DBMSE\Vechile_Service_Management\vehicle-service-booking-system\frontend
cmd /c npm run dev
```
*Web application opens at http://localhost:5173*
